# README

So in essence this is an app under its very early stages of development. I plan to add a few more features in the future, but for now I am still fixing some small bugs with Windows' compatibility as well as ensuring that the app actually functions properly. If you want to try the program, download the .ZIP file. 

**Heads up: You will most likely get a Defender SmartScreen warning. In order to use the app, you will have to press "Learn more" and then "Run anyway".** (My app isn't officially signed and recognized by Microsoft, which is why the warning pops up).



# Installation

You will have to install the file by first building it with _build.bat_. I advise against using _build.ps1_, since many a times Windows Defender stops the script from working fully; so unless you disable Windows Defender wholly (which I do not recommend) the script may not fully work. 


# Known issues

- Pinned apps on the top left of the dock do not function properly
- Dragging sliders does not function properly
